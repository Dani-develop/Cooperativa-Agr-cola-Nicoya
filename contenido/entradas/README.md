# Entradas de campo por desarrollar

Preparar al menos dos noticias agrícolas por autores distintos para probar Autor/Editor. El grupo redactará contenido útil con fuentes y señalará datos simulados del caso cuando corresponda.

Registrar autor, revisor Editor, fecha, estado y URL. Conservar una entrada ajena para el intento de edición denegado del otro Autor. No confundir Autor con un rol capaz de administrar páginas o plugins.
