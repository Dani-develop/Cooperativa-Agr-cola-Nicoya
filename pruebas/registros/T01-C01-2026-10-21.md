### Declaración de la zona DNS

Se definió el dominio interno del proyecto como:

```text
cooperativa.internal
```

En `/etc/bind/named.conf.local` se declaró la zona maestra:

```conf
zone "cooperativa.internal" {
    type master;
    file "/etc/bind/db.cooperativa.internal";
};
```

Posteriormente se creó `/etc/bind/db.cooperativa.internal` con los registros SOA, NS y A:

```dns
$TTL 604800

@   IN  SOA ns.cooperativa.internal. admin.cooperativa.internal. (
        2026102201 ; Serial
        604800     ; Refresh
        86400      ; Retry
        2419200    ; Expire
        604800 )   ; Negative Cache TTL

@       IN  NS  ns.cooperativa.internal.
@       IN  A   192.168.50.1
ns      IN  A   192.168.50.1
www     IN  A   192.168.50.1
server  IN  A   192.168.50.1
```

### Restricción de consultas y recursión

Se configuró `/etc/bind/named.conf.options` para limitar el acceso al servidor DNS:

```conf
acl "clientes-internos" {
    127.0.0.1;
    192.168.50.0/24;
};

options {
    directory "/var/cache/bind";

    listen-on {
        127.0.0.1;
        192.168.50.1;
    };

    listen-on-v6 { none; };

    recursion yes;
    allow-query { clientes-internos; };
    allow-recursion { clientes-internos; };

    forwarders {
        8.8.8.8;
        8.8.4.4;
    };
};
```

La configuración se validó y aplicó mediante:
