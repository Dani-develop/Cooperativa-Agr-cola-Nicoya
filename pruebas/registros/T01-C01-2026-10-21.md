
La configuración fue validada antes de aplicarse mediante:

```bash
sudo netplan generate
sudo netplan try
```


Los resultados confirmaron:

- Red `192.168.50.0/24` accesible mediante `enp0s8`.
- Ruta por defecto conservada mediante `enp0s3`.
- Conectividad a Internet correcta, con 3 respuestas recibidas de 3 enviadas y 0 % de pérdida.
