# Entregables finales

Pendientes de elaborar a partir de procedimientos y resultados reales.

1. Documento técnico: problema, alcance, decisiones, arquitectura, instalación, administración, permisos, respaldo/restauración, pruebas, limitaciones y referencias APA 7.
2. Presentación: problema, solución, decisiones, evidencia y guion de demo.
3. Infraestructura disponible para demostración en vivo.
4. Versión identificada del repositorio y copia de contingencia protegida fuera de Git.
